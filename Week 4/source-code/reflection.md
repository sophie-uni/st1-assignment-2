Before using AI, I built a basic Python script using standard input and output statements to handle two records. After identifying limitations in my initial code, I wrote an enhanced function to improve it.
When I shared my code with the AI (Copilot), it analyzed the functions, highlighted limitations, and suggested architectural improvements. By asking guiding questions, AI also helped me to understand the requirements better. Later, when I prompted it to "create a simple beginner-friendly Python function that stores patient name, practitioner name, and appointment time without a database or GUI," the AI simply added a single comment on line 24 explaining the subsequent code, leaving the core logic unchanged. Because no functional code was modified, the script still ran, but this highlighted that I needed to provide more detailed, specific prompts.
To verify the AI's output, I manually reviewed the suggested edits, tested whether the code was executed correctly, and evaluated if the logic aligned with my system requirements before deciding whether to accept or reject the changes. Ultimately, the engineering responsibility remained with me: formulating clear business rules, designing the underlying architecture, handling edge cases, and making final implementation decisions.
